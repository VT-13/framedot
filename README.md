# FrameDot

The first-viewport FrameDot product demo, published as a static site on GitHub Pages.

The camera simulation works with drag, arrow keys, and Home to center. Joining the waitlist increments a persistent aggregate counter through Abacus; no email or name is requested. A successful join is remembered in that browser to avoid repeat clicks. Because the public counter endpoint does not authenticate visitors, the total is an approximate interest signal, not a verified count of unique people.
